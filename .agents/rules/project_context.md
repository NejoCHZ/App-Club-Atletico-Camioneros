# Contexto del Proyecto (CACC)

Siempre tené en cuenta y consultá las especificaciones, alcance, roles, funcionalidades y stack tecnológico definidos en [project.md](file:///d:/Proyecto%20Camioneros/project.md) para cualquier desarrollo, refactorización o consulta dentro de este repositorio.

## Puntos Clave del Sistema:
- **Institución:** Club Atlético Camioneros de Córdoba (CACC).
- **Stack:** Angular (Frontend), C# 13 / .NET 9 (Backend API REST), SQL Server (BD).
- **Portales & RBAC:** Portal Administrativo, Portal Deportivo, WebApp Semáforo QR. Acceso diferenciado por 5 roles (Tesorero, Coordinador, DT, Médico, Don QR). Los jugadores NO tienen acceso.
